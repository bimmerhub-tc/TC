# 99.0.15 测试候选

完整效果：大屏画布1533×525，位置(204,104)，中心位置基本保持；可见轮廓加宽10%。沿用此前主体上下边缘和斜边，仅在左右封口各约31像素范围修顺。外沿约8像素边带使用35%不透明度，中心完全不透明，仅保留轻微抗锯齿。

源/解码保留1400×480。大屏约放大9.5%，不是1:1；普通仪表中心裁取1088×480（左右各156像素），不拉伸。导航安全区保留，上游自动投射、HUD与独立纹理遮罩保留。

此前未使用99.0.14新分辨率补丁的车辆，需要通过APP更新CarPlay补丁，按提示重启车机并重新连接手机；实际手机输出分辨率尚需现场确认。

目标编译ABI、两条GLES遮罩采样、地图模式切换及安装包校验通过。尚未实车验证，轮廓不宣称精准贴合原厂；99.0.8全黑根因仍未确认，本版不保证已排除该问题。未远程操作车机。
