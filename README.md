# TC 仪表大屏地图投射

# 99.0.20 修复Store构建失败 · 导航卡片测试版

修复99.0.19相对模块引用缺少.js后缀导致的车机构建失败。已按Store实际链接规则检查全部模块；原卡片逻辑和地图效果不变。

本次先验证能否读取并显示真实导航数据，箭头样式后续再打磨。未实车验证。

组件配套：APP 99.0.20、waze-on-cluster 99.0.18、cluster-render 99.0.15。三个组件版本号不同是正常的；渲染器沿用99.0.15，不必重复安装同一版本。

APP新增可选的独立转向/车道卡片和到达信息卡片。只读活动CarPlay/Android Auto导航元数据，上方显示方向、距离、可用路名和车道，下方单行显示“剩余时长 · 剩余里程 · 到达时刻”。整体不透明度38%，原厂地图槽卡片为大屏的75%。无有效数据、导航结束或地图隐藏时移除卡片。

这不是控制手机地图原生卡片的接口；视频原有提示可能同时存在。不同地图是否提供这些字段，必须实车确认。模拟测试通过不代表高德、百度或其他地图已经兼容。

保留99.0.15的大屏地图轮廓、位置和自动投射逻辑；原厂位置地图改为完整1088×480源，大屏源为1400×480。切换源尺寸时按APP提示应用补丁并重启主机后生效，未生效前完整旧帧暂时等比适配。

## Store测试步骤

1. 来源使用 `bimmerhub-tc/TC`，选择 Releases，然后检查更新。
2. 更新地图服务至99.0.18、APP至99.0.20；渲染器确认99.0.15。按安装提示重启。
3. 打开地图APP，连接手机并启动一条导航，确认地图已经投射。
4. 在APP勾选“独立车道/转向卡片”“独立到达时间卡片”，按“应用卡片设置”。开关在当前APP进程内有效，进程重启后需重新应用。
5. 观察APP卡片状态，并记录使用的手机地图、转向/车道/到达信息是否出现及是否更新。结束导航后确认卡片消失。
6. 若未显示，记录状态（等待地图/等待数据/绘制提交/渲染错误）或拍照；“绘制提交”只代表本地已提交，不代表仪表上已确认可见。可按“关闭独立卡片”停止本次测试。

安装声明已通过Store官方校验器对车机备份接口数据库的检查；本地元数据、过期清理、图层、透明度、原厂尺寸及APP页面测试通过。未连接或远程操作车辆。
